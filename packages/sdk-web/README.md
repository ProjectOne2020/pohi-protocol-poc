# `@pohi-protocol/sdk-web`

Official TypeScript Web Client SDK for the Proof of Human Intent (PoHI) protocol.

## Overview

High-precision browser DOM event listener capture (`keydown`, `keyup`, `touchstart`, `touchend`), volatile typed memory buffer isolation (`Float64Array`), zero-overwrite memory sanitization, and WebWorker WebAssembly ZK prover integration (`snarkjs`).
