## 2. Community & Technical Assistance

### GitHub Discussions & Issues
- **Technical Questions**: For general usage questions, circuit parameters, or integration architecture, search existing [GitHub Issues](https://github.com/ProjectOne2020/pohi-protocol-poc/issues).
- **Bug Reports**: If you encounter an unexpected issue in SDK code, smart contracts, or circuit compilation, submit a detailed issue report including system specifications and error logs.
- **Feature Requests**: Feature suggestions and research enhancement proposals should be submitted via GitHub Issues using the `enhancement` label.

---
